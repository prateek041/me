## Files

- A post is a `.md` or `.mdx` file anywhere under `writings/`. Its folder path is
  its URL: `writings/tech/ebpf/kprobes.md` is `/writings/tech/ebpf/kprobes`.
- `.md` is plain Markdown. `.mdx` can also use the components below.
- Files starting with `_` are never published.
- A header image for `thoughts` and `life` posts goes at `public/<same path>.jpg`.

## Frontmatter

```yaml title="frontmatter"
title: "Post title"          # required
date: "November 20, 2026"    # required, any date format JS can read
description: "Shown in search results, link previews and RSS."
status: WIP                  # optional label next to the date
tags: [ebpf, networking]     # optional
draft: true                  # optional, hidden in production
```

An unknown key, or a missing title or date, fails the build with the file name in
the error. That's how a typo like `desciption` gets caught.

## Code

Fenced code is highlighted at build time, follows the light and dark theme, and
has a copy button.

```c title="hello.c" {4} showLineNumbers
#include <stdio.h>

int main(void) {
    printf("hello, kernel\n");
    return 0;
}
```

The first line of that block is `` ```c title="hello.c" {4} showLineNumbers ``:
`title` adds a file name, `{4}` highlights line 4 (ranges like `{2-5}` work too),
and `showLineNumbers` numbers the lines.

### Inline code

Normal backticks give `inline code`.
